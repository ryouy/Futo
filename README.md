## 使い方

1. 制限するアプリやサイトを選ぶ
2. 使いたくなったら「ふと」で目的を選び、少し待つ
3. 使うか、やめておくかを選ぶ
4. 決めた時間が過ぎたら、自動で制限に戻る

## 主な機能

**ログイン不要**

- アプリ・カテゴリ・サイトの制限と、時間を決めた一時解除
- 待ち時間を設けた、制限全体の一時停止・終了
- 目的や感想のグラフ、日ごとの解除回数
- 朝夜の振り返りと、任意の通知
- 日本語・英語対応、4色のテーマ

**必要なときだけ、Googleログイン**

- **共有**：選んだ記録を、リンクやフレンドに共有
- **フレンド**：リンク・コード・QRで招待し、承認してつながる
- **バックアップ**：記録と設定をGoogle Driveのアプリ専用領域に保存
