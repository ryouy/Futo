## 使い方

1. ふだんは、選んだアプリやサイトを **制限したまま** にします。
2. 使いたくなったら「ふと」を開き、何をするかを選んで、少し待ちます。
3. 待ったあとで、使うか、やめておくかを選びます。
4. 使うときは、決めた時間だけ解除され、そのあと自動で制限に戻ります。

## 主な機能

**ふだんの使い方（ログイン不要）**
- アプリ・カテゴリ・ウェブサイトの制限（Screen Time）。使いたくなったら、少し待ってから、使うかを選びます。
- 一時解除のあとは、決めた時間で、自動で制限に戻ります。
- 制限全体の一時停止（1分待つと30分）と、制限の終了（30分待つ）。待機のあいだ、制限は続きます。
- 記録（今週・今月・すべて）：結果・目的・感想のグラフと、日ごとの一時解除の回数。
- 朝夜の振り返りと、任意の通知（お出かけのおすすめは、1日の回数だけ設定）。
- 制限された画面（シールド）を「ふと」らしい見た目に。
- 日本語と English、テーマカラー4色。

**使うときだけ（任意）**
- Googleログイン：共有・フレンド・バックアップの本人確認に使います。要求するのは名前だけです。
- 共有：選んだ項目だけを、グラフで、リンクやフレンドに共有できます（全期間も選べます）。
- フレンド：招待リンク・コード・QRで招待します。承認されるまで、記録は見えません。
- Google Driveバックアップ：Driveのアプリ専用の領域に、記録と設定を保存します。

**広告**：ひと呼吸の待機画面の最下部に、小さなバナー広告が1枠あります（Google AdMob）。ほかの画面には出ません。広告の表示やクリックは、解除の条件に関係しません。気分・回答・利用履歴は、広告に送りません。

記録と設定は、共有やバックアップを選ばない限り、**この端末の中だけ**に保存します。詳しくは、[プライバシーポリシー](https://futo-share.vercel.app/privacy)。
