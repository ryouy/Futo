# ふと

「ふと開く」から、「ふと気づく」へ。スマホを開く前に少し立ち止まり、使い方を自分で選ぶための iPhone アプリ（Swift / SwiftUI）。

現在は**開発者本人向けの最初の試作**です。公開版ではなく、解除を防止する管理アプリでもありません。

- 試せること：使う前の振り返り（目的選択 → 3分待機 → 自分で選ぶ）、実機での選択アプリの制限開始／終了（Screen Time）
- まだできないこと：一時解除と自動再制限
- デモモード：シミュレーターでも動きますが、実際のアプリは制限しません
