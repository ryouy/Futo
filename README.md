# ふと

**「ふと開く」から、「ふと気づく」へ。**

スマホを開く前に、ひと呼吸。使うかどうかを、自分で選ぶ iPhone アプリです。

## 使い方

1. ふだんは、選んだアプリやサイトを **制限したまま** にします。
2. 使いたくなったら「ふと」を開き、何に使いたいかを選んで、少し待ちます。
3. 待ったあとで、使うか、やめておくかを選びます。
4. 使うときは、決めた時間だけ解除され、そのあと自動で制限に戻ります。

## 主な機能

- アプリ・カテゴリ・ウェブサイトの制限（Screen Time）
- 記録（今週・今月・すべて）と、朝夜の振り返り
- 任意の通知（初期はオフ）
- シミュレーターで試せるデモモード

記録は端末の中だけに保存します。

## 動かすには

iOS 17 以降と Xcode 15.3 以降が必要です。制限を実際にかけるには、実機と署名の設定が必要です。手順は [docs/SETUP.md](docs/SETUP.md) を見てください。

詳しい状況は [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md) にあります。
