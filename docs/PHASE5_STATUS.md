## 追加（2026-10-30）
- バックアップを有効にした直後に、**最初の1回を自動で保存**する。ただしDriveにすでにバックアップがある場合は、新しい端末の空の記録で上書きしないよう、自動では保存しない（「バックアップから戻す」を案内）。
- 保存先：Driveの「アプリ専用のデータ（appDataFolder）」。Driveのファイル一覧には出ず、Driveの設定 →「アプリの管理」から確認・削除できる。容量は、本人のDriveの容量に数えられる。

## 検証したこと
- Swift：ロジックのテスト 113件 成功（Phase 4までの既存テストを含む）。
- iOS：`swiftc -typecheck`（iphoneos SDK）エラーなし。Xcodeプロジェクトへの登録済み。

## 検証できていないこと
- 実際の Google Drive での許可・保存・取得・削除。Google Cloud の Drive API 有効化・同意画面のスコープ追加。
- 実機での画面操作、別端末への復元。
- 許可に使ったGoogleアカウントが、ログインのアカウントと異なる場合の扱い（メールのスコープを取らないため、アプリは判別できない。画面で同じアカウントを選ぶよう案内している）。
- 大量の記録（数万件）でのバックアップ時間。

## 既知の制約
- バックアップは1ファイル（最新のみ）。履歴は持たない。
- 自動バックアップ・定期同期は、ありません。
- 復元は追加のみ。端末で削除した記録を、Driveの内容に合わせて消すことはしない。
- アプリを削除しても、Drive上のバックアップは残る（Googleアカウントの「アプリの管理」から削除できる）。
