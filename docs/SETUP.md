# セットアップ

## 必要なもの

- Mac と Xcode 15.3 以降（iOS 17 SDK）。最低OSは iOS 17。
- 実機で制限を試す場合：iPhone（iOS 17 以降）、Apple ID（Xcode にサインイン済み）、USBまたは同一ネットワーク接続。
- 外部ライブラリはありません。

## 1. 開く

```
open Futo.xcodeproj
```

スキーム `Futo` を使います。コードは VS Code で編集できますが、**新しい .swift ファイルを追加したときは、Xcode のプロジェクトに追加が必要**です（Xcode で対象フォルダを右クリック → Add Files to "Futo"…、Target は Futo）。既存ファイルの編集だけなら不要です。

## 2. シミュレーターで試す（署名不要）

1. Xcode の上部で iPhone シミュレーターを選び、Run（⌘R）。
2. 初回画面で「デモで試す」。
3. デモでは実際のアプリは制限されません。画面上部に常にデモの表示が出ます。
4. 待機を短くするには、設定 → Debug → 「待機を10秒にする」（Debugビルドのみ。Releaseには存在しません）。

シミュレーターで「実機で設定する」を選んでも、Screen Time の認証と制限は利用できません（エラー表示になります）。これは想定どおりで、実機で確認してください。

iOS シミュレーターが無い場合は、Xcode → Settings → Platforms から iOS をダウンロードしてください。

## 3. 実機で試す（あなたの操作が必要）

署名情報はリポジトリに含めていません。以下を Xcode で設定します。

1. Xcode → Settings → Accounts に Apple ID を追加。
2. プロジェクト `Futo` → TARGETS `Futo` → **Signing & Capabilities**。
   - **Team**：自分の Team を選ぶ（現在は空欄）。
   - **Bundle Identifier**：初期値 `com.ryouy.futo` は仮の値です。他の人と重複しない自分用の値に変更してください。変更したら `FutoTests` 側（`<Bundle ID>.tests`）も合わせます。
   - **Family Controls** が Capability の一覧に表示されていることを確認。`Futo/Futo.entitlements` に `com.apple.developer.family-controls` を設定済みです。表示されない場合は「+ Capability」→「Family Controls (Development)」を追加してください。
   - 「Automatically manage signing」はオンのまま。赤いエラーが出る場合は内容に従います（Apple Developer Program の状況により異なります。条件は Xcode に表示される内容で確認してください）。
3. iPhone で **開発者モード** をオン：設定 → プライバシーとセキュリティ → デベロッパモード（再起動が必要）。
4. iPhone を接続して信頼し、Xcode 上部で実機を選んで Run。初回は 設定 → 一般 → VPNとデバイス管理 で開発元を信頼する必要がある場合があります。
5. アプリで「実機で設定する」→「許可する」→ 制限するアプリを **1つ** 選んで保存 →「制限を始める」。

### 配布について（今回は対象外）

開発用署名と、TestFlight／App Store 配布用の Family Controls 権限の申請は別です。配布に進むときは [Apple の資料](https://developer.apple.com/documentation/familycontrols/requesting-the-family-controls-entitlement) を確認してください。

## 4. 実機確認チェックリスト

実施したら `[x]` にして結果をメモしてください。

- [ ] 認証をキャンセル → 制限されず、「許可する」で再試行できる
- [ ] 対象未選択 → 「アプリを選ぶ」が出て、制限は始まらない
- [ ] カテゴリやWebサイトを選んで保存 → 「アプリを選び直してください」と出て、保存されない
- [ ] 1アプリを選んで「制限を始める」→ 対象アプリを開くとOS標準のシールドが出る
- [ ] 対象外のアプリは本アプリの制限で妨げられない
- [ ] 制限中でも「ふと」を開ける
- [ ] 「使う前に、ひと呼吸」→ 目的選択 →（デバッグで10秒）待機 → 「今はやめる」→ 制限が続く
- [ ] 「使いたい」→ 記録のみで制限が続く（対象アプリはまだシールドされる）
- [ ] ホームで「制限を終了」→ 対象アプリのシールドが消える
- [ ] 設定アプリで Screen Time の許可を取り消す → 「ふと」に戻ると状態が修正される（制限中と表示し続けない）
- [ ] アプリを強制終了して開く → 設定と進行中の振り返りが保たれる
- [ ] 端末を再起動 → 制限状態を確認して結果をメモ（保証していません）
- [ ] 制限中は「制限するアプリを変更」が無効になっている
- [ ] 待機中にホームボタン／画面ロック → 残り時間が止まり、戻ると続きから進む
