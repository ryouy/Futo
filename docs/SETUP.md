# セットアップ

## 必要なもの

- Mac と Xcode 15.3 以降（iOS 17 SDK）。最低OSは iOS 17。
- 実機で制限を試す場合：iPhone（iOS 17 以降）、Apple ID（Xcode にサインイン済み）、USBまたは同一ネットワーク接続。
- 外部ライブラリはありません。

## 1. 開く

```
open Futo.xcodeproj
```

スキーム `Futo` を使います。コードは VS Code で編集できますが、**新しい .swift ファイルを追加したときは、Xcode のプロジェクトに追加が必要**です（Xcode で対象フォルダを右クリック → Add Files to "Futo"…、Target は Futo）。既存ファイルの編集だけなら不要です。

## 2. シミュレーターで試す（署名不要）

1. Xcode の上部で iPhone シミュレーターを選び、Run（⌘R）。
2. 初回画面で「デモで試す」。
3. デモでは実際のアプリは制限されません。画面上部に常にデモの表示が出ます。
4. 待機時間はDebugビルドでは自動で10秒です（Releaseは180秒。切り替えUIはありません）。

シミュレーターで「実機で設定する」を選んでも、Screen Time の認証と制限は利用できません（エラー表示になります）。これは想定どおりで、実機で確認してください。

iOS シミュレーターが無い場合は、Xcode → Settings → Platforms から iOS をダウンロードしてください。

## 3. 実機で試す（あなたの操作が必要）

署名情報はリポジトリに含めていません。以下を Xcode で設定します。

1. Xcode → Settings → Accounts に Apple ID を追加。
2. プロジェクト `Futo` → TARGETS `Futo` → **Signing & Capabilities**。
   - **Team**：自分の Team を選ぶ（現在は空欄）。
   - **Bundle Identifier**：初期値 `com.ryouy.futo` は仮の値です。他の人と重複しない自分用の値に変更してください。変更したら `FutoTests` 側（`<Bundle ID>.tests`）も合わせます。
   - **Family Controls** が Capability の一覧に表示されていることを確認。`Futo/Futo.entitlements` に `com.apple.developer.family-controls` を設定済みです。表示されない場合は「+ Capability」→「Family Controls (Development)」を追加してください。
   - 「Automatically manage signing」はオンのまま。赤いエラーが出る場合は内容に従います（Apple Developer Program の状況により異なります。条件は Xcode に表示される内容で確認してください）。
3. iPhone で **開発者モード** をオン：設定 → プライバシーとセキュリティ → デベロッパモード（再起動が必要）。
4. iPhone を接続して信頼し、Xcode 上部で実機を選んで Run。初回は 設定 → 一般 → VPNとデバイス管理 で開発元を信頼する必要がある場合があります。
5. アプリで「実機で設定する」→「許可する」→ 制限するアプリを **1つ** 選んで保存 →「制限を始める」。

### 一時解除（Phase 2・試験機能）に必要な設定

一時解除には Device Activity 拡張（`FutoMonitor`）と App Group が必要です。

1. TARGETS `Futo` と `FutoMonitor` の両方で Signing & Capabilities を開き、Team を選ぶ（`FutoMonitor` の Team は設定済みの値を引き継いでいますが、画面で確認してください）。
2. 両方のターゲットで **App Groups** と **Family Controls** が表示されていることを確認する。
   - App Group は `group.<Bundle ID>`（初期値は `group.com.ryouy.futo`）。両ターゲットで**同じ値**にする。
   - Bundle ID を変更した場合は、`Futo/Futo.entitlements` と `FutoMonitor/FutoMonitor.entitlements` の `group.…` と、`FutoMonitor` の Bundle ID（`<Bundle ID>.monitor`）も合わせる。拡張の Bundle ID は本体の ID で始まる必要がある。
   - Xcode で「+ Capability」から App Groups を追加し、グループを登録（または選択）する。
3. Run して実機に入れる。拡張が組み込まれない・署名エラーが出る場合は、そのメッセージを確認してください。
4. App Group が使えない状態では、アプリは Phase 1 の動作（一時解除なし）に自動で戻り、「この設定では一時解除は使えません」と表示します。

一時解除の仕組み：「使いたい」を選んで解除するアプリを選ぶと、Device Activity の監視（16分の区間、対象アプリの利用しきい値）を登録できた場合だけ制限を外します。登録に失敗したら制限は維持されます。利用がしきい値（Releaseは5分、Debugは検証しやすいよう1分）に達するか、区間が終わると、拡張が再制限します。アプリを前面に戻したときにも、解除したままになっていないか確認して補正します。

### 配布について（今回は対象外）

開発用署名と、TestFlight／App Store 配布用の Family Controls 権限の申請は別です。配布に進むときは [Apple の資料](https://developer.apple.com/documentation/familycontrols/requesting-the-family-controls-entitlement) を確認してください。

- [ ] ホーム上部に「ふと」と、右に時計・歯車のアイコンがある（ナビゲーションバーは無い）。チュートリアルで、記録・設定の場所が正しく光る
- [ ] チュートリアルの文が句の切れ目で改行され、行の途中で折り返さない。インジケータが無い。「スキップ」「つぎへ」が画面下部に固定され、光る場所と重ならない。最後は「準備はできました。」の下に「はじめる」
- [ ] 設定の通知と、ひと呼吸タブの朝夜の振り返りで、時刻がトグルの左にある
- [ ] 制限していないときのホームの一言が「…」で切れていない

## 説明→ホームの遷移・「はじめる」ボタンの再確認

- [ ] 初回説明の最後からホームへ、画面が白く光らず、緑からゆっくり溶けるように切り替わる（そのあとチュートリアルが始まる）
- [ ] チュートリアル最後の「はじめる」が、レモン色の目立つボタンになっている

## 設定の文・ダークモードの確認チェックリスト

- [ ] 設定の各タブに、小さなグレーの見出し・説明文が無い
- [ ] ダークモード（iPhoneの外観をダークに）で、ホーム・ひと呼吸の画面・記録・設定・テーマ4色が、黒すぎず、やわらかい雰囲気に見える。文字が読みやすく、設定の行の背景が浮いていない。気になる色があれば、画面と一緒に教えてください

## 初回説明のスライドの確認チェックリスト

- [ ] 「つぎへ」を押すと、手でスワイプしたときと同じように、前のページが左へゆるっとスライドして次のページが入ってくる（中身が消えずに流れる）
- [ ] スワイプでも同じ速さで切り替わり、最初のページで右・最後のページで左には、抵抗がかかって進まない
- [ ] ホームの「ふと」の左に、アイコンが無い

## 振り返りの全画面カード・制限中の追加・チュートリアル背景の確認チェックリスト

- [ ] Debugの「朝の振り返り」「夜の振り返り」で、画面全体をやわらかく覆うカードが出て、「わかった」で閉じる。閉じたあと、アプリを開き直しても出ない。ホームの上には、カードが残っていない
- [ ] 制限中に「＋」でアプリ・カテゴリ・サイトを追加でき、追加したものにすぐシールドが出る。選択画面でチェックを外して保存しても、外したものは制限されたまま
- [ ] 制限中は、各行の「－」が出ない（制限をはずしている間と、一時解除中は出る）
- [ ] チュートリアルの吹き出しが、白でなくテーマ色の薄い背景で、目立ちすぎない

## はみ出し・はじめる・ふとの大きさの確認チェックリスト

- [ ] 長い名前（ウェブサイトなど）を制限しても、ホームの一覧と「どれを使いますか？」の行が右端からはみ出さず、名前は「…」で省略され、「－」や選択の丸が見える
- [ ] チュートリアルの「はじめる」がテーマカラー。ホームの「ふと」が一回り小さい

## 感想カード・ボタンの強弱の確認チェックリスト

- [ ] 一時解除が終わってホームに戻ると、「さっきの時間は、どうでしたか？」が、画面全体を覆うカードで出る。答える／「答えない」で閉じ、もう出ない。ホームの中にはカードが残っていない
- [ ] 一覧の「－」を押すと、確認なしですぐ制限から外れる
- [ ] 「今も使いたいですか？」は「使いたい」が薄く「やめておく」が濃い。解除の選択画面でも、「選んだものを使う」が薄く「やめておく」が濃い

## 英語対応の確認チェックリスト

- [ ] 設定 → その他 →「言語 / Language」で English を選ぶと、アプリ全体（ホーム・ひと呼吸の画面・記録・設定・通知の設定・チュートリアル・初回説明）が、再起動なしで英語になる。日本語に戻せる
- [ ] 英語で、文字が長くて見切れる・不自然に折り返す箇所が無い（あれば、画面と一緒に教えてください）
- [ ] 英語で、朝の振り返り（Debugのボタン）が「Yesterday,」で始まる。日付・時刻が英語の書式（24時間）になる
- [ ] 英語で通知を送る（お出かけ通知）と、本文が英語。言語を切り替えたあと、予約済みの通知も新しい言語になる

## 英語の見直し・初回説明の言語切り替えの確認チェックリスト

- [ ] 初回説明の右上に「日本語 | English」があり、押すと白いカプセルがすべって切り替わり、説明の文言がすぐ変わる
- [ ] 英語で、設定のタブ名（Lock / Breaths / Alerts / More）が省略されない。ホームの一言が「…」で切れない
- [ ] 英語で、Debugのホーム下部のボタン（Morning check-in / Evening check-in / Go-outside nudge）が崩れず、1行に並ぶ
- [ ] 英語の言い回しがゆるく自然か（直したい文言は、`EnglishStrings.swift` の英語を直すだけで反映できます）
